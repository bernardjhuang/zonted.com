## How it works: generated by AI, finished by code

![PixelForge pipeline: a source portrait becomes a strict 4×4 sprite sheet, then deterministic Python repairs and extracts a transparent walking GIF.](https://img.zonted.com/resources/pixelforge-launch/how-it-works-pipeline.png)

*The production line: source photo → strict 4×4 sheet → repaired, transparent, walking. (Yes, that's me.)*

1. **Upload a portrait.** Any clear front-facing photo works.
2. **AI generates the sheet.** The model renders a 4×4 directional walk grid in a consistent pixel-art style.
3. **Deterministic Python finishes the pack.** Code strips the key color, snaps every frame’s feet to a uniform baseline, and exports clean transparent assets.

Step 3 is the actual product. Raw AI sprite sheets are 90% impressive and 100% unusable in a real game engine: background artifacts bleed into edges, characters bob up and down off their baseline as they walk, and cell boundaries drift by a few pixels. Almost every “AI sprite generator” demo stops at step 2 and hands you a flat PNG you still have to clean up in Aseprite. The unglamorous Python post-processing — the part a model cannot vibe its way through — is what makes the output immediately playable.

## The build: days, not weeks

PixelForge went from blank repo to live checkout in a few days using my standard [plan-3x-build-once loop](https://zonted.com/posts/plan-3x-build-once/): three independent model plans reconciled into one spec before GPT 5.5 wrote the code. Prompting the image generator took hours; hardening the deterministic Python slicer took days — reliably detecting grid lines, keying out backgrounds without chewing into dark outlines, and locking 16 frames of feet to a single floor line. The web wrapper stayed intentionally minimal: one landing page, one file upload, one Stripe checkout button, and a live public bench showing recent generations.

## Ship or Die

Deadlines shipped this product as much as code did. I joined [Ship or Die](https://www.ship-or-die.com/) — Marc Lou and Jack Friks’ accountability community built around a single rule: **launch a startup in 30 days or get permanently banned.** Entry costs $269, progress check-ins are daily, and missing your deadline gets you thrown overboard in public with no refund.

The irony isn’t lost on me given [my own benchmark on stakes priming](https://zonted.com/posts/stakes-priming-surface-area/): threatening an LLM doesn’t improve its output, yet paying $269 for a Discord server to threaten *me* got a working product out the door in under a week. Forcing the scope down to “one core feature and a live Stripe button” is the exact antidote to builder perfectionism.
